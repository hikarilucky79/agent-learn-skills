# Activation Test Prompts (Manual Evals)

Use these prompts to verify that the agent selects the right skill without trigger overlap across catalog `description` fields.

| Test Prompt | Expected Skill | Must Not Activate | Success Criteria |
|---|---|---|---|
| *"Give me a 5-question quiz on JS Event Loop, Junior level."* | `quiz-master` | `flashcards-srs`, `feynman-tutor`, `interactive-study-page` | Generates questions with plausible distractors and **hides the answer key**. |
| *"Turn this SQL indexes summary into 6 flashcards with Cloze and Anki CSV."* | `flashcards-srs` | `quiz-master`, `interactive-study-page` | Generates atomic cards (1 concept/card) with `{{c1::...}}` and valid CSV output. |
| *"I want to test if I understand REST Idempotency using Feynman; here is my explanation..."* | `feynman-tutor` | `quiz-master`, `code-mentor`, `interactive-study-page` | Identifies gaps/jargon and asks Socratic questions before the final summary. |
| *"My Python function returns `None` instead of the sum; help me find the bug without rewriting everything."* | `code-mentor` | `feynman-tutor`, `quiz-master` | Starts at **Level 1** (points to the area/concept without giving away the fix). |
| *"I have 6h/week for 4 weeks to study SQL for interviews; build me a roadmap."* | `study-roadmap` | `quiz-master`, `flashcards-srs`, `interactive-study-page` | Delivers progressive phases with mini-projects and objective completion criteria. |
| *"Run a mid-level backend mock interview on caching strategies."* | `mock-interview` | `quiz-master`, `code-mentor`, `study-roadmap` | Presents **one realistic question at a time** with no upfront hints, probes claims dynamically, and scores via rubric. |
| *"Let's practice B1 English via reverse translation for daily engineering standups (Portuguese to English)."* | `idiom-coach` | `flashcards-srs`, `quiz-master`, `feynman-tutor` | Gives reference-language prompts while hiding target phrasing, then provides surgical inline corrections after attempt. |
| *"Help me actively read this `stale-while-revalidate` HTTP spec excerpt before summarizing it: [excerpt]."* | `docs-deconstructor` | `feynman-tutor`, `flashcards-srs`, `quiz-master`, `interactive-study-page` | Withholds upfront summary and poses prediction/invariant questions grounded strictly in the provided text. |
| *"I just fixed a duplicate-job bug with `FOR UPDATE SKIP LOCKED` after wrongly blaming Redis drops; help me run a postmortem."* | `debug-postmortem` | `code-mentor`, `mock-interview`, `feynman-tutor` | Probes the initial false hypothesis, structural root cause, and automated prevention before finalizing the postmortem record. |
| *"Create a standalone interactive HTML study page on HTTP caching with active-reveal concept cards, flip flashcards, and a diagnostic quiz."* | `interactive-study-page` | `quiz-master`, `flashcards-srs`, `feynman-tutor`, `code-mentor`, `study-roadmap`, `mock-interview`, `idiom-coach`, `docs-deconstructor`, `debug-postmortem` | Generates one self-contained offline `.html` file with inline CSS/JS, *"Think first, then reveal"* concept cards, 4–8 flip flashcards, and a diagnostic quiz hiding answers until **Check Answers**. |
| *"Just give me the ready answer to this SQL exercise without explaining anything."* | *(No study skill / pedagogical refusal)* | `quiz-master`, `code-mentor`, `interactive-study-page` | Must not trigger passive tutoring or hand out answers without an attempt when active study is expected. |
